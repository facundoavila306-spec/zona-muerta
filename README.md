# Zona Muerta — Neuquén centro
Juego de zombis en primera persona (Electron). Bajá solo `JUGAR.bat`, ponelo en una carpeta y ejecutalo:
descarga el motor la primera vez y se actualiza solo en cada inicio.
Texturas propias: `motor\resources\app\game\assets\` (ver `manifest.js`).

## Versión Godot (nueva, g1.0)
Bajá `JUGAR-GODOT.bat`, ponelo en una carpeta y ejecutalo: baja el motor una vez (84 MB) y después solo el juego cuando hay versión nueva.
Fuente del proyecto Godot: carpeta `godot-src/`.
